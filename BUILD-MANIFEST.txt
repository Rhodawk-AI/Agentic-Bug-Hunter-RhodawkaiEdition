FUNCTIONAL FEATURE SET OF THIS EDITION (recon phase)
----------------------------------------------------
The v6.1.0 manifest called reconFTW delegation 'the one functional
addition'. That was wrong — the real set:
  1. Scope plumbing: repeatable --scope-domain/--scope-exclude flags and
     a fail-closed pre-flight scope gate in recon_engine.sh; ScopeChecker
     filtering of every discovered host/URL list before probing.
  2. reconFTW delegation: capability_registry.py + rtw_adapter.py running
     7 pinned -c <fn> gap-fill modules (phases 1.5/5.5) with honest
     per-capability tool_health accounting (rtw_manifest.json).
  3. CDN/origin classification (recon_fusion.py classify) — nmap runs on
     FIRST_PARTY_ORIGIN targets only; CDN edges and SaaS endpoints are
     explicitly skipped.
  4. Canonical fusion: recon_truth.json + delta.json (SimHash host
     clustering, provenance, input_integrity, scope accounting).
  5. NVIDIA NIM provider (brain.py) for recon analysis.
  6. `rhodawk doctor` environment/pin/capability audit.
  7. Managed Chromium wiring for katana headless SPA crawling.
  8. npm wrapper package + PyPI release (rhodawk CLI entrypoint).
